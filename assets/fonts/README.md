# Self-hosted fonts

The site serves these WOFF2 files locally; it does not request a font CDN at runtime.

- **Be Vietnam Pro** — static normal weights 400, 600, and 800; Latin and Vietnamese subsets.
- **Source Serif 4** — variable normal weight range 200–900; Latin and Vietnamese subsets.

The files come from Fontsource npm packages version 5.3.0:

- `@fontsource/be-vietnam-pro`
- `@fontsource-variable/source-serif-4`

Both typefaces are licensed under SIL Open Font License 1.1. See the two `OFL-*.txt` files in this directory.
